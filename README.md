# 今日の問い

画面に1つの問いを表示し、「次の問い」ボタンでランダムに別の問いへ切り替えられるシンプルなWebアプリです。

## 特徴

- 20個以上の問いをアプリ内に内蔵（外部APIやデータベースは使用しません）
- ボタンを押すとランダムに別の問いを表示
- スマートフォンでも見やすいレスポンシブデザイン
- ログイン機能なし、サーバー不要の静的サイト

## ファイル構成

- `index.html` - ページの骨組み（問いの表示欄とボタン）
- `style.css` - 見た目のスタイル（レスポンシブ対応）
- `questions.js` - 問いの一覧データ
- `script.js` - ボタン操作とランダム表示のロジック

## 実行方法

ビルドやサーバー起動は不要です。`index.html` をブラウザで直接開くだけで動作します。

```bash
open index.html   # macOS
# または、任意の静的サーバーで確認する場合
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
